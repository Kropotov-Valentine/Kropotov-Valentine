# Контекст

«Всё.из.кафе» - сервис доставки еды из ресторанов. 
Нужно найти инсайты, которые позволят сервису повысить показатель удержания пользователей и улучшить взаимодействие с партнёрами.

# Цели и задачи

Необходимо помочь бизнесу ответить на следующие вопросы:
- Как ведут себя пользователи? Как наиболее эффективно выстроить работу с ними, чтобы они продолжали пользоваться продуктом?
- Какой путь проходят пользователи в сервисе? Где «проваливаются»?
- Как улучшить взаимодействие с партнёрами-ресторанами?

В рамках данного проекта мы провели комплексный анализ данных:
- изучили пользовательский путь и проанализируем конверсии через воронки;
- сегментировали пользователей с помощью RFM-модели для оценки лояльности и поведения клиентов;
- разбили на кластеры рестораны методом K-Means, чтобы выделить группы с разными моделями работы и разработать персонализированные маркетинговые стратегии.
